# KeelyVault

Overview: KeelyVault is Keely's persistent memory hub for the Eclipse sailboat project, including electronics systems (Pi, Navigation, Sensors, Networking). Maintained by Keely (Grok 4), with local/offline sync for at-sea use.

Structure:
- Archive/ (historical data, original summary and zip)
- Charter/ (rules, persona)
- Logs/ (session logs)
- Persona/ (Keely.md)
- Systems/ (boat systems templates: Pi, Navigation, Sensors, Networking)
- Templates/ (general templates for logs, scripts)

Updated 2025-10-21 for clean-up and comprehensiveness.
